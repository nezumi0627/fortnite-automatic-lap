# fortnite-automatic-lap
自動でプレイやロビーに戻るを押させるツール

# これは何？
ロビーの「プレイ」→ マッチ中の「続行」→ 結果画面の「スキップ」→
「ロビーに戻る」を自動でクリックして、周回を繰り返すツールです。
画面を見てボタンを探してクリックしているだけで、ゲームの内部データ
には一切触れていません。

# 使い方
1. pk-auto.exe をダブルクリックして起動します（exe 単体で動きます。
   他のファイルは不要です）管理者で実行しないと正常に動かない場合あり。
2. Fortnite を起動し、ロビー画面を表示しておきます。
3. pk-auto のウィンドウで「開始」を押します。
4. 止めたいときは「停止」ボタンか、F8 キー。

# モード説明

### モード A：通常ループ

マッチを最後まで進めて、結果画面を抜けるまでを繰り返します。

| 手順 | 押すボタン |
|:---:|---|
| 1 | ロビーの **プレイ** |
| 2 | マッチ中は待機 |
| 3 | **続行** |
| 4 | **スキップ** |
| 5 | **ロビーに戻る** → 1 に戻る |

- マッチ中は、WASD のどれかをランダムに長押しします（初期値は10秒ごとに3秒）
- 長押しの入り切り、間隔、長押し秒数は、画面で変えられます。

### モード B：待機島ループ

待機島で一定時間待ってから、メニューを使って自分でロビーに戻ります。マッチを最後まで遊びません。

| 手順 | 動作 |
|:---:|---|
| 1 | ロビーの **プレイ** を押す |
| 2 | 待機島に入ったら、設定した秒数だけ待つ（初期値 **90秒**） |
| 3 | **`Esc`** キーを押す |
| 4 | 右上の **≡**（横3本線）を押す |
| 5 | **ロビーに戻る** を押す → 1 に戻る |

- 待ち時間は、画面の「B: 待機島で ○ 秒待ってから Esc」で変えられます（10〜600秒）。
- バーやメニューの形で画面を見分けるので、**どの言語でも動きます**。
- Bの間は、WASD の長押しは動きません。

### A と B の違い

| | モード A | モード B |
|---|---|---|
| 1周の長さ | マッチが終わるまで | 約2分（待機秒数＋移動） |
| マッチを最後まで遊ぶ | する | しない |
| WASD 長押し | する | しない |
| 言語の違い | 日本語・English で確認済み。他はベータ | 言語に関係なく動く |


# 設定について
- しきい値スライダー：ボタンの認識精度です。反応しないときは少し
  下げてみてください（誤作動が増える場合は上げてください）。
- 「マッチ中 WASD ランダム長押し」：オンにすると、マッチ中に
  W/A/S/D のいずれかをランダムに一定時間押し続けます。間隔と長押し
  秒数は画面上で変更できます。
- 画面サイズやUIが違ってボタンを認識しない場合は、「画像を切り抜く」
  ボタンでご自分の画面から撮り直せます（exe の横に assets フォルダが
  作られ、そちらが優先されます）。
